Cómo correr tu server

Después de descargar el zip, seguí los pasos de tu sistema. Necesitás Java instalado: si falta o es otra versión, el script te avisa cuál y cómo instalarla.

Linux / macOS

  1. Descomprimí el zip.
  2. Abrí la carpeta que se creó.
  3. Abrí una consola dentro de esa carpeta (en el explorador, clic derecho y "Abrir terminal aquí").
  4. La primera vez ejecutá ./start.sh. Descarga el jar oficial, prepara todo y arranca el server.
  5. Para iniciarlo cuando quieras, ejecutá ./iniciar.sh.

Windows

  1. Descomprimí el zip (clic derecho, "Extraer todo").
  2. Abrí la carpeta que se creó.
  3. La primera vez hacé doble clic en start.bat. Descarga el jar oficial, prepara todo y arranca el server.
  4. Para iniciarlo cuando quieras, hacé doble clic en iniciar.bat.

Después de arrancar

  1. Esperá a ver Done! en la consola. Ahí el server ya está listo.
  2. En Minecraft: Multijugador, Agregar servidor, y escribí localhost si jugás en la misma PC.
  3. Para que entren tus amigos hace falta abrir el puerto 25565 (mirá "Problemas comunes").
  4. Para cerrarlo bien escribí stop en la consola. No cierres la ventana a la fuerza.

start.sh / start.bat se usan una sola vez: se borran solos al terminar de instalar y dejan iniciar en su lugar. Los mundos, plugins y mods quedan en la misma carpeta.

Problemas comunes

Dice que necesita otra versión de Java

El script te muestra qué versión pide tu server y el comando para instalarla. Cada versión de Minecraft pide una distinta (8, 16, 17 o 21). Si tenés varias instaladas, asegurate de que java -version muestre la correcta.

Address already in use / Failed to bind to port

Hay otro programa (o otro server) usando el puerto. Cerralo o cambiá server-port en el server.properties.

You need to agree to the EULA

El script ya crea eula.txt con eula=true. Si lo borraste, creá ese archivo con esa línea.

OutOfMemoryError o mucho lag

Subí la RAM, pero dejá 1 o 2 GB libres para el sistema. Bajá view-distance y simulation-distance, o probá el preset PC modesta. En Paper, Chunky ayuda a pregenerar el mundo.

Mis amigos no pueden entrar

Abrí el puerto 25565 TCP en tu router (port forwarding) y en el firewall, y pasales tu IP pública. Si no podés abrir puertos, un túnel como playit.gg o una VPN tipo Tailscale lo resuelven.

Outdated client / Outdated server

La versión del juego tiene que coincidir con la del server. En Paper/Purpur, ViaVersion deja entrar clientes más nuevos.

Los mods o plugins no cargan

Plugins van en plugins/ y mods en mods/, y deben ser para tu versión de Minecraft y tu loader (Fabric no corre mods de Forge). Fabric casi siempre necesita Fabric API.

Forge o NeoForge tardan muchísimo la primera vez

Es normal: el instalador descarga todas las librerías. Las siguientes veces arranca rápido.

Unsupported class file major version 65 (WorldEdit u otro plugin no carga)

El plugin está compilado para Java 21 y tu Paper es un build viejo que no sabe leerlo. Pasa con el Paper 1.20 original, que quedó congelado con una versión vieja de ASM. Solución: usá Paper 1.20.1 o más nuevo (tu mundo se conserva) y volvé a iniciar. Por eso la página ya no ofrece el 1.20 exacto para Paper, Purpur y Folia.

already locked (session.lock)

Dice que el mundo está bloqueado por otra instancia. Primero fijate que no tengas otro server abierto con la misma carpeta (pgrep -af java en Linux, el Administrador de tareas en Windows). Si no hay ninguno, el lock quedó de un cierre brusco: borrá world/session.lock y volvé a iniciar. Si pasa seguido en un disco NTFS en Linux, mové la carpeta del server a tu home.

Permission denied al ejecutar start.sh

Ejecutalo con sh start.sh o dale permiso con chmod +x start.sh.

En Windows dice que curl no se reconoce

Curl viene en Windows 10 y 11. En versiones más viejas, actualizá Windows o descargá el jar a mano.
